# v0.2.1

Desktop-to-Desktop delegation from Codex Desktop/CLI to an already running DeepSeek Harness Desktop. Reuse the configured model provider, Skills and allowed Tools without an additional DeepSeek API key or a separate DSH CLI/Web runtime.

- Support DSH Desktop **0.2.0-rc.2 / Cordis 4.0.4** and **0.2.1-rc.1 / Cordis 4.0.5**.
- Report connected Desktop versions in setup and connection diagnostics.
- Add per-agent permission guards and improve task cancellation handling.
- Provide Codex plugin, Desktop adapter and source archives with SHA-256 checksums.

Install both the Codex plugin and Desktop adapter. See the [setup guide](https://github.com/Cryocell77/codex-deepseek-harness-desktop-bridge/blob/v0.2.1/docs/CODEX-PLUGIN.md).

Experimental prerelease. Test coverage and known limitations are documented in [validation](https://github.com/Cryocell77/codex-deepseek-harness-desktop-bridge/blob/v0.2.1/docs/VALIDATION.md).
